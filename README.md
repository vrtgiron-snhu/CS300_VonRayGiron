# CS300_VonRayGiron

Throughout CS 300, I worked on two projects that helped me better understand how data structures and algorithms are used in software development.

**1. What was the problem you were solving in the projects for this course?**

The main problem I was solving in Projects One and Two was creating a course advising system for ABCU. The goal was to help academic advisors organize computer science courses, display them in alphanumeric order, and look up specific courses along with their prerequisites. In Project One, I focused on designing the program using pseudocode and comparing different data structures. In Project Two, I used what I learned to develop the actual program in C++.

**2. How did you approach the problem? Consider why data structures are important to understand.**

I approached the problem by breaking it down into smaller tasks and figuring out which data structure would work best. In Project One, I compared vectors, hash tables, and binary search trees to understand their advantages and disadvantages. I ended up choosing a hash table because it allows efficient searching and storing of course information. I learned that understanding data structures is important because choosing the right one can make a program more efficient and easier to manage.

**3. How did you overcome any roadblocks you encountered while going through the activities or project?**

One of the challenges I encountered was turning my pseudocode from Project One into working C++ code for Project Two. It was easier to write out the steps than to actually implement them. I also had to make sure the program could properly read the course data, store the information, and display the correct prerequisites. To work through these challenges, I reviewed my pseudocode, checked my code for errors, and tested different parts of the program instead of trying to fix everything at once.

**4. How has your work on this project expanded your approach to designing software and developing programs?**

These projects taught me the importance of planning before jumping straight into coding. Before taking this course, I would usually focus more on getting a program to work rather than thinking about the best way to design it. Project One helped me understand why pseudocode and runtime analysis are useful when planning software. Project Two gave me the opportunity to apply that planning to an actual program. Moving forward, I will spend more time considering how my programs should be structured before writing the code.

**5. How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?**

Working on these projects helped me realize that writing a program is not just about making sure it runs correctly. It is also important to make the code easy to understand, update, and troubleshoot. I learned to organize my code into separate functions, use meaningful variable names, and avoid unnecessary repetition. Having a clear structure also makes it easier to add features or make changes later without having to rewrite the entire program. Overall, CS 300 has helped me become more comfortable with C++ and has given me a better understanding of how to develop programs that are both efficient and organized.
